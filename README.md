# Nina Carducci - Photography Portfolio

A photography portfolio website optimized for SEO and performance, developed as part of the OpenClassrooms Web Developer program.

## Overview

Nina Carducci is a professional photographer's portfolio website. This project focuses on SEO optimization, accessibility improvements, and performance enhancements.

## Features

- Responsive image gallery
- Lightbox for full-size image viewing
- Image carousel
- Contact section
- Schema.org structured data
- Optimized images (WebP format)
- SEO meta tags

## Optimizations Performed

### Performance
- Image compression and conversion to WebP
- Minified CSS and JavaScript
- Responsive images with appropriate sizes
- Lazy loading implementation

### SEO
- Semantic HTML structure
- Meta tags (title, description, Open Graph)
- Schema.org structured data for local business
- Alt text for all images

### Accessibility
- ARIA labels where needed
- Proper heading hierarchy
- Keyboard navigation support
- Color contrast compliance

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap
- Font Awesome
